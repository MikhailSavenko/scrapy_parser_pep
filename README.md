# PEP Parser

## Описание

Этот проект представляет собой парсер для сбора информации о PEP (Python Enhancement Proposals) с сайта [https://peps.python.org/](https://peps.python.org/). Парсер извлекает данные о PEP и сохраняет их в два CSV-файла:

1. **Файл со списком всех PEP**: содержит номер, название и статус каждого PEP.
2. **Файл со сводкой по статусам PEP**: отображает количество документов в каждом статусе и общее количество всех документов.

## Функциональность

Парсер реализует следующие возможности:

- **Сбор ссылок на документы PEP**: Стартовая ссылка установлена на [https://peps.python.org/](https://peps.python.org/). Парсер собирает ссылки на страницы документов PEP.
- **Парсинг страниц PEP**: Каждая страница PEP парсится для извлечения номера, названия и статуса PEP. Для этого используются CSS- и XPath-селекторы.
- **Использование Scrapy Items**: Класс `PepParseItem` используется для хранения данных о каждом PEP. Класс содержит следующие атрибуты:
  - `number` (номер PEP)
  - `name` (название PEP)
  - `status` (статус PEP)
- **Сохранение данных в CSV файлы**:
  - **Файл со списком PEP**:
    - Файлы сохраняются в директорию `results/` с именем по маске `pep_ДатаВремя.csv`, например, `pep_2024-09-05T14-30-00.csv`.
    - Содержит три столбца: `number`, `name`, `status`.
  - **Файл со сводкой по статусам**:
    - Файлы сохраняются в директорию `results/` с именем по маске `status_summary_ДатаВремя.csv`, например, `status_summary_2024-09-05_14-30-00.csv`.
    - В файле два столбца: `Статус` и `Количество`.
    - Файл формируется через Pipeline, который суммирует количество документов PEP в разных статусах и добавляет итоговую строку с общим количеством документов.

## Как использовать

1. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```

2. Запустите парсер:
   ```bash
   scrapy crawl pep_parser
   ```

3. Найдите результаты в директории `results/`.

## Файлы

- `settings.py`: Конфигурация проекта, включая настройки Feeds для сохранения файлов со списком PEP.
- `pipelines.py`: Реализация Pipeline для создания файла со сводкой по статусам.
- `items.py`: Определение класса `PepParseItem`.

## Примечания

- Для создания CSV файлов с помощью Pipeline используются методы стандартной библиотеки `csv`.
